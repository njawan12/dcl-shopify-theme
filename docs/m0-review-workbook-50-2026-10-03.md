## Findings that survive the 50-review pass

### F1 — Generic ease-of-use is not whitespace

Multiple incumbents receive explicit praise for intuitive, beginner-friendly, easy, flexible or self-managed operation. This **falsifies** any positioning built primarily around “easy/no-code Shopify theme.”

### F2 — Support is structurally part of premium-theme value

Support appears repeatedly even in highly positive reviews: configuration guidance, code fixes, updates, app diagnosis, integration and customization. DCL must treat support contacts per license and support minutes per license as product/economic metrics.

### F3 — Feature breadth can coexist with decision friction

Positive breadth/flexibility reviews and friction reviews coexist within the same themes. This supports testing—not assuming—the narrower hypothesis that bounded job-specific compositions can reduce consequential decisions for recurring commercial work.

### F4 — Starting state deserves direct testing

Broadcast's templates are praised; Impact has direct evidence of an installed empty state disappointing a merchant. Therefore the M1 baseline must be a strong incumbent-style preset/template, not an empty generic page.

### F5 — Mobile/media and update resilience remain engineering differentiators only if demonstrably better

Image/cropping, update, integration and support issues recur as signals. These are quality opportunities, not unique marketing propositions.

## G3 gate decision

**G3 — ≥50 recent competitor reviews: PASS WITH LIMITATION.**

The quantitative threshold of 50 coded official reviews is met. The evidence includes strong counter-evidence and does not justify prevalence claims. Two Pipeline observations are older than the preferred recent window because the accessible current official review page exposed only two 2026 reviews; this limitation is explicit and does not change the cross-sample threshold.

This gate should be reopened only if:
- the competitor set materially changes;
- a source is shown to be non-official/incorrect;
- the final M0 review requires a stricter recency definition; or
- new merchant evidence identifies a problem category absent from this coding taxonomy.
